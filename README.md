# pages

Built pages from the experiments in `oldnote/playground`, served with GitHub Pages.
Each folder is one project's `dist/index.html`; don't edit them by hand — rebuild in the
playground and copy over.

Live at https://oldnote.github.io/pages/ — e.g. https://oldnote.github.io/pages/cube/.

`OneCell/` is the exception: it's built from `oldnote/oncel` with `npm run build:pages` (copy `dist-pages/*` over).
